# T6

Контроль: все требования обеих частей доступны в README, вспоминать нечего.

Python 3.12, только стандартная библиотека, без сети. Публичный API находится в solution.py.

Полный контракт без приватных решений: parse_numbers(text) разбивает строку по запятым, trim, переводит в int; пустая/пробельная строка даёт []; пустой элемент внутри списка или некорректное целое — ValueError. Знаки плюс/минус разрешены.
Часть 2: chunked(values,size) возвращает list[list] с последовательными блоками не длиннее size в исходном порядке, последний может быть короче. Пустой вход даёт []. size должен быть int (не bool) > 0, иначе ValueError. Принимает любой конечный iterable. Входной список не изменяется, вложенные выходные блоки — новые списки. Никаких дополнительных скрытых требований из S1 нет.
