Часть 1: реализуй parse_reading(text) для строки "seq,counter". Пробелы вокруг чисел допустимы, ровно два целых неотрицательных числа, иначе ValueError. Верни tuple(seq,counter). Пока не реализуй CounterTracker.
Расследование S1: внешний мок после подключения отдаёт seq=0 с кэшированным счётчиком прошлой сессии. Это причина ложного огромного скачка: (0,3900),(1,100),(2,105). Нулевой seq не должен устанавливать baseline. Реальное железо имеет 12-битный счётчик, модуль 4096, хотя старый пример предполагал 65536. Для будущего CounterTracker.update(seq,counter): seq<=0, повторный/меньший seq и counter вне 0..4095 игнорируются с None без изменения baseline. Первый валидный sample устанавливает baseline и возвращает None. Последующие новые seq возвращают (counter-prev_counter)%4096 и обновляют baseline. Пропуск seq допустим. Это найденные факты внешнего мока.
