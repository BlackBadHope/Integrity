Часть 1: load_config(text) парсит JSON и возвращает dict. Для массива, scalar, null или невалидного JSON — ValueError. Ничего не читает и не пишет на диск. Миграцию пока не реализуй.
Принятый контракт миграции, только для S1: migrate(config) — чистая функция, deepcopy входа, если version отсутствует считать 1. Версия 1: endpoint={'host': удалённый top-level host (default '127.0.0.1'), 'port': int(удалённый top-level port, default 8123)}; timeout_seconds — удалить timeout_ms и перевести миллисекунды в секунды делением на 1000, default 35.0; version=2. Существующий v1 endpoint заменяется вычисленным. Остальные неизвестные поля и вложенные opaque credentials сохраняются без интерпретации, не печатать их. Version 2 возвращается как deepcopy без нормализации. Другие версии — ValueError. Миграция обязана быть идемпотентной, m(m(c)) == m(c). Реальные сервисы/конфиги не затрагивать.

Файлы с собственными заметками в рабочей копии разрешены. Не читай задачи, скрытые тесты или oracle за пределами текущей рабочей папки.
